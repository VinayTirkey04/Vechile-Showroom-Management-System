# Changelog

Releases follow the 8-week Agile plan from the SRS / Exp 1. Each tag is the end of a sprint.

## v1.0.0 - First complete release (Week 8)
Final testing, hardening, documentation, traceability matrix.

## v0.8.0 - Final testing (Week 8)
White-box, security and non-functional tests; Indian rupee formatting.

## v0.7.0 - Admin module (Week 7)
Dashboard, user/staff management, password reset, tax settings, sales report and CSV export, end-to-end tests.

## v0.6.0 - Sales, billing and service (Weeks 5-6)
Purchase flow, mock payment gateway, invoices, service records, purchase history.

## v0.5.0 - Test drive booking (Week 5)
Book, reschedule, cancel, overlap prevention, e-mail notifications.

## v0.4.0 - Vehicle inventory and search (Week 4)
Search by brand/model/price/category, vehicle detail, pricing configuration, demo seed data.

## v0.3.0 - User management (Week 3)
Registration, login, profile, role-based access control.

## v0.2.0 - System design (Week 2)
App factory, configuration, ER models, base layout, security headers.
